# ✈️ Aerodynamic Lift Calculator

An interactive Python script designed to calculate the aerodynamic lift generated by an aircraft wing and evaluate takeoff feasibility based on real-time physics parameters.

## 🚀 Key Features
- **Physics-Based Formula:** Calculates lift force using $L = \frac{1}{2} \cdot \rho \cdot v^2 \cdot S \cdot C_L$.
- **Takeoff Evaluation:** Compares generated Lift ($L$) with total Aircraft Weight ($W$) to issue a takeoff decision.
- **Dynamic User Inputs:** Takes air density, velocity, wing surface area, and lift coefficient dynamically.

## 🛠️ Concepts Demonstrated
- Python Functions (`def` and `return`)
- Float arithmetic & exponentiation (`**`)
- Decision logic (`if / else` conditionals)
- Command-line user input handling

## 💻 How to Run
1. Run the script in Python 3.x or Google Colab.
2. Enter requested flight parameters when prompted:
   - Velocity (m/s)
   - Air Density (kg/m³)
   - Wing Area (m²)
   - Lift Coefficient ($C_L$)
   - Aircraft Weight (N)
